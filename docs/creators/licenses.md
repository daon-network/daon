## 📚 Creative Commons Licenses

### **CC BY-NC (Attribution Non-Commercial)**
```
Allows: Attribution + Non-commercial use
Blocks: Commercial use without permission

Perfect for:
✅ Academic researchers
✅ Educational content creators  
✅ Open-source documentation
✅ Community projects

Example: "You can share and adapt my research papers, but companies can't sell courses based on them without permission."
```

### **CC BY-SA (Attribution Share-Alike)**
```  
Allows: Attribution + Derivative works must use same license
Blocks: Closed-source commercialization

Perfect for:
✅ Open-source project documentation
✅ Educational materials
✅ Community resources
✅ Wikipedia-style content

Example: "You can build on my work, but any improvements must be shared with the same license."
```

### **CC BY (Attribution)**
```
Allows: Almost anything with attribution
Blocks: Very little

Perfect for:
✅ Public domain-style sharing
✅ Maximum distribution
✅ Commercial collaboration
⚠️ Minimal protection

Example: "Use my work however you want, just mention my name."
```

## 🔄 Changing Licenses

### **Can I Change My License Later?**
```
Generally: NO - licenses are permanent

Exception: You can add MORE permissions:
✅ All Rights → Liberation License ✅
✅ Liberation → Creative Commons ✅  
✅ CC BY-NC → CC BY ✅

You CANNOT take back permissions:
❌ CC BY → All Rights ❌
❌ Liberation → All Rights ❌
❌ CC BY → CC BY-NC ❌
```

### **Best Practice**
Start with **more restrictive** licenses and relax them later if desired:
1. **All Rights Reserved** (maximum protection)
2. **Liberation License** (anti-AI protection)
3. **CC BY-NC** (academic friendly)
4. **CC BY** (maximum sharing)

## 🔍 FAQ

### **"Which license protects against AI training?"**
**Liberation License v1.0** specifically blocks commercial AI training without compensation.

### **"Can I use different licenses for different works?"**
Yes! Mix and match based on each work's needs. Academic papers might use CC BY-NC while your novel uses Liberation License.

### **"What if someone violates my license?"**
You have **legal recourse** with blockchain-timestamped evidence. The stronger your license, the more damages you can claim.

### **"Do platforms respect these licenses?"**  
Major platforms increasingly recognize creator licensing. DAON provides **technical enforcement** where platforms support it.

### **"What about fair use?"**
All DAON licenses **explicitly preserve fair use** rights - commentary, criticism, parody, and education remain legal.

### **"Can I license for commercial use later?"**
Yes! You can always **grant additional permissions** or **sell commercial licenses** separately.
